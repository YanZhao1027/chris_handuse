# TENDON / 05 - goal-conditioned in-hand reorientation
V4 frozen learned grasp prior; new goal-conditioned residual actor with 90 observations and 10 bounded continuous actions. 5 independent tendon forces and 5 basal yaw corrections. Two seconds of initial grasp/lift, then four seconds of manipulation. Temporary fixture disengages at 1s; requested goal quaternion is calculated from the actual object quaternion at 2s. Only contacts and joint actuation rotate the free body. Wrist pose stays fixed after lift. Target is signed rotation about world Z, not arbitrary SO(3) control. Training curriculum from ±15–30 degrees to ±25–60 degrees. Reward: retention, geodesic quaternion error, error progress, angular speed and action/force cost. Success requires full quaternion error <12 degrees and angular speed <1.5 rad/s for final 0.4s, retention throughout manipulation, at least two loaded digits, bounded drift <35 mm and minimum lift >35mm; all trials count including failed grasps.
Sphere and ellipsoid stages train separately using existing GPU MuJoCo Warp. Ellipsoid axes are radius*[aspect,1,1/aspect], aspect sampled 1.06–1.18 at nominal domain difficulty; mass/inertia/geometry updated consistently. No finger self-collision or real hardware calibration. Rotation of a sphere is measured by the material-frame quaternion (equivalent to a fiducial mark); there is no applied external torque on the object. V4 prior remains unchanged.
Probes: 256 sphere worlds, 256 ellipsoid worlds; fixture and target timing assertions; no nonfinite states. Frozen V4 at ±30deg: sphere 3/256 goal success, 223/256 retained; ellipsoid 0/256 goal success, 250/256 retained. CPU reference uses independent implementation and exact same control schedule; quaternion tests pass.
Stages:
- sphere: 8192 worlds x 32 x 180 updates.
- ellipsoid: 4096 worlds x 32 x 120 updates, initialized from best sphere policy.
- each 48 independent CPU validation scenes with signed goals ±25/40/60deg; best chosen by full goal success, retention, capped error.
- final independent CPU blind seeds 550000+, compare frozen V4, sphere V5 and ellipsoid V5 on both object shapes, nominal and outside training parameter range; save representative actual trajectories. Test sets not used for training/selection.
Progress: python3 progress.py
Checkpoints: runs/sphere01 and runs/ellipsoid01 (best.pt/latest.pt/history.json/config.json).
